\begin{remark}[The generic-set discipline]\label{rem:generic-discipline}
From Chapter~\ref{ch:penalization} through
Proposition~\ref{prop:no-singular-points}, \emph{every} statement is made for
an arbitrary set satisfying the $\omega$-minimality inequality of
Definition~\ref{def:omega-minimal}.  The liquid-drop minimiser enters only
through Lemma~\ref{lem:quasiminimal}, which supplies one such $\omega$.  This
is not stylistic: the same generic theory is applied a second time, with the
Coulomb term deleted, in the equality case of the isoperimetric inequality
(Chapter~\ref{ch:rigidity}).  A formalisation that hard-codes the liquid-drop
energy into these chapters will have to be written twice.
\end{remark}
